# ADEPTUS MECHANICUS TERMINAL

A grimdark industrial telemetry dashboard built with PySide6 and Qt Designer.

Inspired by:
- Warhammer 40K machine terminals
- industrial HMI systems
- robot operator consoles
- retro-futuristic telemetry displays

## About

This project is a sci-fi inspired desktop dashboard application designed as a fictional machine terminal / robot control interface.

The application simulates:
- telemetry monitoring
- command systems
- industrial HMI panels
- operator consoles
- machine status tracking

The project was created to practice:
- Qt Designer
- PySide6 GUI architecture
- real-time dashboard logic
- layout systems
- industrial interface design
  
## Features

- Telemetry monitoring panel
- Command interface
- Emergency system controls
- Real-time terminal logs
- Modular Qt layout system
- Sci-fi industrial theme
